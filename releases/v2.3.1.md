# XJTLU-MCP v2.3.1

- 图书馆内置登录窗口支持在 `xjtlu.edu.cn` 及其子域之间进行 HTTPS 跳转，自动填密码仍只在已确认的 UIM 登录表单执行。页面失败时会显示原因，可重试或在系统浏览器打开预约页。
- 新增 Lite 更新包。它先检查已登记的安装及 Electron 文件，再在原目录更新工作台和插件资源。运行时缺失、不兼容或只有解压版时，请使用同版本的完整安装包或解压包。
- 自选安装和原地升级遇到受保护目录时，会通过 Windows UAC 请求写入程序文件。安装登记、快捷方式、数据和 Agent 配对继续归原 Windows 用户。

## Windows x64 下载

| 文件 | 使用方式 |
| --- | --- |
| `XJTLU-MCP-2.3.1-win-x64-setup.exe` | 完整安装包，适合首次安装和覆盖升级。 |
| `XJTLU-MCP-2.3.1-win-x64.zip` | 完整解压后双击 `XJTLU-MCP.exe`。 |
| `XJTLU-MCP-2.3.1-win-x64-lite-setup.exe` | 更新使用 Electron 45.2.1 且运行文件完整、兼容的已登记 x64 安装。 |
| `SHA256SUMS.txt` | 核对三个下载文件的 SHA-256。 |

安装版也可从 Windows「已安装的应用」卸载。安装版和解压版都包含 `Uninstall.exe`，默认保留本机数据。选择删除时，同一 Windows 用户的工作台副本共用的数据也会清除。发布包未签名。
