# XJTLU-MCP v3.0.0

## 本版更新

- **西浦邮箱**可从工作台连接学校邮箱，查看收件箱、已发送和邮件正文。登录从学校入口开始，若跳转到 Microsoft，可在官方窗口完成验证。邮件正文保留段落、粗体、列表、引用和表格。
- **本机邮件历史**可在「账号与设置 → 西浦邮箱」开启。加载过的邮件列表和打开过的正文会按邮箱分开加密保存。再次连接同一邮箱时，历史与最新邮件合并显示。点击「清空已存邮件」可删除本机副本。
- **LMC 成绩与提交状态**支持每门课的个人 Grades。单项作业、测验和互评读取学校开放的提交结果。测验显示各次得分及来源，作业可查看学校显示的历史提交。
- **Agent 工具**新增 `get_lmc_grades`、`get_email_list`、`get_email_information` 和 `send_email`。邮件发送默认关闭，须在设置页开启，退出邮箱或重启后会关闭。

## Windows x64 下载

| 文件 | 使用方式 |
| --- | --- |
| `XJTLU-MCP-3.0.0-win-x64-setup.exe` | 完整安装包，适合首次安装和覆盖升级。 |
| `XJTLU-MCP-3.0.0-win-x64.zip` | 完整解压后双击 `XJTLU-MCP.exe`。 |
| `XJTLU-MCP-3.0.0-win-x64-lite-setup.exe` | 更新已登记的兼容 x64 安装，要求 Electron 45.2.1 和完整的运行文件。检查未通过时请使用完整安装包。 |
| `SHA256SUMS.txt` | 核对三个下载文件的 SHA-256。 |

覆盖升级沿用已登记的安装目录，并保留学校账号、本机设置和 Agent 配对。安装版和解压版都包含 `Uninstall.exe`，卸载时可选择是否保留本机数据。发布包未签名。
