# XJTLU-MCP V2.0

适用于 Windows x64。

- 新增 Learning Mall Core 课程目录、通知和原文件下载。通知可隐藏登录提醒，课程列表可按名称或最近访问顺序查看。
- eBridge 新增成绩查询、课程总评和分项成绩。可选择在本机加密缓存课表、课程列表和考试安排。
- 新增本机 MCP 服务与 ChatGPT 桌面端的「XJTLU 校园助手」插件，提供 16 项工具。应用显示插件安装、启用、目录登记和密钥配对状态。
- 固定侧栏和顶部导航。学校提示风险登录时可在官方窗口手动完成验证码验证。

## 下载与升级

1. 退出旧版 XJTLU-MCP。
2. 将 `XJTLU-MCP-2.0.0-win-x64.zip` 完整解压到新目录，双击其中的 `XJTLU-MCP.exe`。保留同目录的 DLL、`resources` 和 `locales`。
3. 确认新版运行正常后，可保留旧版以便回退。若要沿用原快捷方式或 Codex 插件目录路径，可以先改名保留旧文件夹，再把新版完整文件夹放到原路径。

同一 Windows 用户的学校账号、学校会话、MCP 密钥和已开启的教务缓存保存在 `%APPDATA%\XJTLU-MCP-AMS`。升级时保留该目录即可沿用。LMC 已下载的资料保存在当时选择的目录，若曾保存到旧程序文件夹内，请先移到其他位置。学校会话过期后按提示重新登录。

已配对的 Codex 插件可继续使用本机地址和密钥。首次连接或重新配对时，在「Agent 连接」打开 ChatGPT 插件页，并查看安装和配对状态。

`SHA256SUMS.txt` 用于核对下载完整性。本版未做代码签名。
