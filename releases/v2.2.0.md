# XJTLU-MCP v2.2.0

- AMS、eBridge、图书馆和 Learning Mall Core 会先尝试自动登录。失败或超时后，点击「手动登录」可打开学校官方窗口。学校要求验证码或二次验证时会直接打开验证窗口。
- ChatGPT / Codex 插件改用共享的 Windows 用户变量 `XJTLU_MCP_TOKEN`。从旧版升级后，在「Agent 连接」的 ChatGPT 卡片点击「重新安装」，然后完全退出并重开 Codex。新会话会加载更新后的插件配置。
- 「Agent 连接」页以程序目录和 Windows 通用路径显示插件位置。

## Windows x64 下载

| 文件 | 使用方式 |
| --- | --- |
| `XJTLU-MCP-2.2.0-win-x64-setup.exe` | 双击安装到当前用户目录，从开始菜单打开。 |
| `XJTLU-MCP-2.2.0-win-x64.zip` | 完整解压后，双击目录里的 `XJTLU-MCP.exe`。 |
| `SHA256SUMS.txt` | 核对两个下载文件的 SHA-256。 |

两个版本都包含运行所需文件，无需另外安装 Node.js 或 Electron。发布包未签名，请核对下载来源与校验值。

## 升级和卸载

覆盖安装或换用新版解压包前，请在系统托盘完全退出工作台。同一 Windows 用户可以继续使用已有的账号、会话和本机数据。升级解压版时，先完整解压新版并确认可用，再移走旧目录。

安装版可在 Windows「已安装的应用」卸载，两个版本也可运行程序目录中的 `Uninstall.exe`。默认保留本机数据。选择删除时会清理当前用户的 `%APPDATA%\XJTLU-MCP-AMS`，同一用户下其他程序副本也共用这份数据。两个选项都会核对并清理工作台支持自动移除的校园 Agent 接入项。豆包中手动添加的连接器请在豆包里移除。
