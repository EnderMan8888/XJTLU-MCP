# XJTLU-MCP V1.0

首个校园信息聚合桌面版本，适用于 Windows x64。

- 首页展示今日课程、教室及 AMS Module 单节签到状态。
- AMS：课程列表、签到率，以及今天、昨天、明天的课程与签到。
- eBridge：课程、Timetables 和个人考试安排。
- 图书馆：按楼层查座、选择时段提交预约、查看我的预约；默认现在至 22:00。
- 公共学校账号在本机加密保存，自动登录，遇验证码或额外验证时由用户完成。

## 下载与运行

下载 `XJTLU-MCP-1.0.0-win-x64.zip`，完整解压后双击 `XJTLU-MCP.exe`。无需安装 Node.js 或 Electron。`SHA256SUMS.txt` 用于核对下载完整性。

## 说明

- 本版本未进行代码签名。
- 账号与学校会话仅存放在本机用户目录，不包含在发布包中。
- 校历目前支持 2026/27 学年；其他学年会提示无法确认教学周。
- 本软件为个人项目，非学校官方应用；学校系统或预约规则变化可能影响功能。
- 已完成主要读取功能的轻量验证，详细测试后续继续；预约提交结果以学校系统为准。
- 项目当前发布的是桌面聚合应用，尚未提供 MCP 服务端。
