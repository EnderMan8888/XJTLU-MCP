# XJTLU-MCP v2.4.0

- 「账号与设置」新增 AMS、eBridge、图书馆和 LMC 的独立自动重登开关，默认关闭。开启后，在线读取遇到会话过期会尝试恢复连接。普通课表查询继续使用缓存，验证码和二次验证仍在学校窗口处理。
- 图书馆登录后优先从学校首页读取楼层和空位数。在旧版楼层请求失败、查座按钮灰掉的场景下，工作台可通过已登录的网页补齐楼层。楼层下拉框显示剩余座位和总座位数。
- eBridge 会话过期后，如果 UIM 显示掩码账号，自动登录通过官方「切换账号」入口填写已保存的学校账号。

## Windows x64 下载

| 文件 | 使用方式 |
| --- | --- |
| `XJTLU-MCP-2.4.0-win-x64-setup.exe` | 完整安装包，适合首次安装和覆盖升级。 |
| `XJTLU-MCP-2.4.0-win-x64.zip` | 完整解压后双击 `XJTLU-MCP.exe`。 |
| `XJTLU-MCP-2.4.0-win-x64-lite-setup.exe` | 更新已登记的兼容 x64 安装，要求 Electron 45.2.1 和完整的运行文件。检查未通过时请使用完整安装包。 |
| `SHA256SUMS.txt` | 核对三个下载文件的 SHA-256。 |

覆盖升级沿用已有安装目录，并保留学校账号、本机设置和 Agent 配对。安装版也可从 Windows「已安装的应用」卸载。安装版和解压版都包含 `Uninstall.exe`，默认保留本机数据。发布包未签名。
