# XJTLU-MCP v2.3.0

- 修复图书馆手动登录可能出现的白屏。窗口可打开学校的访问验证页。遇到页面加载失败时，可以从工作台重新尝试。
- 安装版首次运行时可选择安装目录，也可勾选「在桌面创建快捷方式」。已有安装会在原目录升级，沿用本机账号、会话、缓存和 Agent 配对。

## Windows x64 下载

| 文件 | 使用方式 |
| --- | --- |
| `XJTLU-MCP-2.3.0-win-x64-setup.exe` | 双击安装或在原目录升级。安装完成后可从开始菜单打开。 |
| `XJTLU-MCP-2.3.0-win-x64.zip` | 完整解压后运行目录中的 `XJTLU-MCP.exe`。 |
| `SHA256SUMS.txt` | 核对安装 EXE 和解压 ZIP 的 SHA-256。 |

两个版本均含运行所需文件，无需另装 Node.js 或 Electron。发布包未签名，请从 GitHub Release 下载并核对校验值。

## 升级和卸载

使用旧安装版时可直接运行新版安装器。原路径无法确认时，安装器会暂停升级。使用解压版时，先从系统托盘退出工作台，再完整解压新的 ZIP。

安装版可通过 Windows「已安装的应用」卸载，两种版本也都可以运行程序目录中的 `Uninstall.exe`。卸载时默认保留本机数据，两个选项都会清理支持自动移除的校园 Agent 接入。豆包中的手动连接器可在豆包里移除。选择删除本机数据时，当前 Windows 用户的所有工作台副本都会失去共用的账号、会话和缓存。
