# XJTLU 校园助手 · Codex 本机插件

适用于与 XJTLU-MCP V2.0 运行在同一台 Windows 电脑上的 Codex。插件通过本机 MCP 服务使用全部 16 个工具。

1. 打开 XJTLU-MCP V2.0。在「Agent 连接」开启服务，点击「在 ChatGPT 中安装」。
2. ChatGPT 桌面端打开「XJTLU 校园助手」插件详情页。点击「安装」。
3. 完全退出并重开 ChatGPT，然后开启一个本地 Codex 会话。输入 `/mcp`，或直接问「用 XJTLU 校园助手检查连接状态，再查今天的课表」。

应用会登记本机插件目录，并在打开插件页时完成配对。Codex 插件清单只指定密钥的环境变量名。密钥保存在当前 Windows 用户的 `XJTLU_CODEX_MCP_TOKEN` 环境变量中，供 Codex 启动时读取。重置密钥后再次打开插件页即可配对。使用期间保持 XJTLU-MCP 运行，学校登录和预约确认在该应用内完成。

「Agent 连接」页显示插件是否安装和启用、插件目录是否已登记，以及本机访问密钥是否配对。回到该页面会刷新，也可点击「刷新安装状态」。如果此前已通过详情页安装但目录尚未登记，点击「打开 ChatGPT 插件页」即可登记，重开桌面端后查看本地 Codex 的插件列表。

XJTLU-MCP 随应用提供插件清单。单独的插件 ZIP 可作为本机 Marketplace 源码归档。

如果安装成功但 Codex 握手返回 HTTP 502，检查代理是否转发了本机请求。使用环境变量配置代理时，把 `127.0.0.1,localhost` 加到现有 `NO_PROXY` 列表，再重启 Codex。

插件可从 Codex 插件页卸载。要同时撤销本机配对，可在 XJTLU-MCP 重置访问密钥，并清除此插件的 Windows 用户环境变量。
