# Learning Mall Core 只读连接探查

日期：2026-11-17（北京时间）。本文保留早期探查记录；后续已接入本地开发版界面，当前实现与验证边界见 [LMC 接入说明](lmc.md)。下文的文件内容提取属于早期探查，当前功能按用户要求仅提供原文件下载。

## 连接结果

- 官方入口为 `https://core.xjtlu.edu.cn/`，学校说明见[访问 Core 指引](https://knowledgebase.xjtlu.edu.cn/article/how-to-access-to-learning-mall-core-platform-341.html)。
- 登录页包含西浦账号入口，经 `/auth/saml2/login.php` 进入 UIM 的 SAML 统一认证。
- 使用应用已有公共账号管理与 safeStorage 解密，在确认的 UIM 官方表单中自动填写并提交，实际登录成功；没有要求用户在聊天中发送密码。
- 使用应用自身的 `persist:xjtlu-core` 会话，没有读取 Edge 或 Chrome 的 Cookie。远程窗口关闭 Node 集成并启用隔离与 sandbox，导航仅允许 Core 与 UIM 的 HTTPS 域名。
- 探查通过临时 Electron 入口完成，使用外层现有运行时；没有安装或升级 Electron。临时入口保存在 `.scratch/core-probe/`，不是生产适配器，不应未经阅读直接重跑。
- 探查只输出条数、字段是否存在及不含查询参数的固定路径，不记录账号、密码、学校 Cookie、sesskey、SAML 请求或签名链接，也不保存学校页面正文或其他学生的信息。

## Module 文件内容验证（后续补充）

- 实际读取一个 Module 文件夹，识别到 1 个 PDF 文件链接及文件名。
- 该 PDF 响应为 application/pdf，接收 4,304,190 字节；本地内存解析得到 23 页，并从抽查的前 2 页提取到 224 个字符。这里只证明文件和部分文字能读取，未完成全篇提取或图片 OCR。
- 另两份资源取得 text/html 文件响应，分别为 20,367 和 36,228 字节，响应提供 HTML 文件名。没有把它们误计为 PDF。
- 一门样本课的 29 个资源入口按图标可识别为 21 个 PDF、4 个压缩包类别、1 个 PowerPoint、1 个 HTML 类别和 2 个未知类别；这只是入口类型识别，不等于全部文件内容已经验证。
- 还有少量普通 resource 直达请求未完成，原因尚未定位；不能据此认定文件不存在或账号没有权限。后续适配应明确处理资源展示页、实际文件地址、登录跳转与网络失败。
- 本轮仅在内存中接收少量文件，不保存学校文件、正文或认证链接，不上传文件；文件样本上限为 8 MiB。PDF 使用本机已附带的 pypdf 检查，没有安装或升级运行时。
- 文件请求使用应用学校会话并显式携带其会话凭据，只允许已确认的 Core 资源与 pluginfile 路由；不得把 Cookie、sesskey 或可能带认证参数的原始文件链接交给 renderer、MCP 或日志。

## 后续接入依据

- 当前能够继续优先实现课程与资源目录、作业基本信息与提交状态，以及讨论列表的只读适配。
- 截止时间需要独立验证：保留学校显示文本，确定时间字段和时区后再标准化；缺少日期显示 unknown，不能推测。
- 成绩必须保留学校的未发布、空值和已有分数语义；不把空白当 0 分。
- 如果使用 Moodle 前端 AJAX，先确认学校实际调用的方法、分页及认证语义；sesskey 只保留在学校会话中，不提供给 renderer 或 MCP。
- 通知已验证方法为 `message_popup_get_popup_notifications`，经同源 `/lib/ajax/service.php` 调用，参数 `useridto=0` 表示当前账号，使用 `newestfirst`、`limit`、`offset` 分页；响应包含 `notifications` 和 `unreadcount`。仅取当前账号，禁止查询其他用户。`subject`、`fullmessage` / `fullmessagehtml`、`timecreated`、`read`、`timeread`、`contexturl`、`component`、`eventtype` 为已验证字段。正文、原文链接可能包含个人信息或认证参数，不能直接打印或保存原始响应；未来输出必须明确投影并清理链接。
- 未来正式接入继续在外层开发工程进行，不修改 sources 中的任何版本存档。
