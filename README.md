# XJTLU-MCP
This repository offers a possible way to offer information of XJTLU(e.g LMC,AMS,e-bridge) to an ai agent by MCP.
Most of the codes are written by ChatGPT.
Because I do not sure if the information can be get from some apis, I use browser extension of Microsoft Edge for the first version to test.
For XJTLU emails, I recommanded you to use outlook(classic), by the application, ai can directly operate the email by COM.
