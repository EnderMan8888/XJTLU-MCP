# XJTLU-MCP V2.1

适用于 Windows x64。

- 「Agent 连接」统一了 ChatGPT、DeepSeek Harness、WorkBuddy、Xiaomi MiMo Code 和 Kimi Code 的安装状态、目录或配置位置，以及安装、卸载和刷新入口。ChatGPT 可直接打开插件页，豆包可手动配置自定义连接器。
- 本机插件统一命名为 **XJTLU-MCP**，版本随工作台更新。修复 DeepSeek Harness 安装后未加载插件、工具未注册的问题。
- Learning Mall Core 的作业条目保留「作业」标签，并显示可用的开放时间和截止时间。
- 最小化窗口或收起到系统托盘后，本机 MCP 连接继续运行。从托盘退出应用即可停止服务。

## 下载与升级

1. 从托盘退出旧版 XJTLU-MCP。
2. 完整解压 `XJTLU-MCP-2.1.0-win-x64.zip`，再运行其中的 `XJTLU-MCP.exe`。
3. 如需更新客户端里的插件，在新版工作台的「Agent 连接」页点「重新安装」。DeepSeek Harness 更新前请从托盘退出客户端，更新后重新打开。

同一 Windows 用户的学校账号、会话、MCP 密钥和已启用的缓存保存在 `%APPDATA%\XJTLU-MCP-AMS`，保留该目录即可沿用。旧版应用和新版使用相同的本机服务端口。

可用 `SHA256SUMS.txt` 核对下载完整性。本版尚未签名。
