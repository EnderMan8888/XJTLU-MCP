# XJTLU-MCP v2.5.0

- LMC 通知页新增「查看附件」，可下载能定位到原帖的公告附件。Agent 也可以用通知 ID 获取附件列表，再用返回的文件 ID 下载。
- MCP 的 `download_lmc_file` 支持可选参数 `savePath`，可把课程资料或公告附件保存到用户指定的本机绝对文件路径。父目录须已存在，已有目标文件会保留。省略参数时继续使用桌面保存窗口。

## Windows x64 下载

| 文件 | 使用方式 |
| --- | --- |
| `XJTLU-MCP-2.5.0-win-x64-setup.exe` | 完整安装包，适合首次安装和覆盖升级。 |
| `XJTLU-MCP-2.5.0-win-x64.zip` | 完整解压后双击 `XJTLU-MCP.exe`。 |
| `XJTLU-MCP-2.5.0-win-x64-lite-setup.exe` | 更新已登记的兼容 x64 安装，要求 Electron 45.2.1 和完整的运行文件。检查未通过时请使用完整安装包。 |
| `SHA256SUMS.txt` | 核对三个下载文件的 SHA-256。 |

覆盖升级沿用已有安装目录，并保留学校账号、本机设置和 Agent 配对。安装版也可从 Windows「已安装的应用」卸载。安装版和解压版都包含 `Uninstall.exe`，默认保留本机数据。发布包未签名。
